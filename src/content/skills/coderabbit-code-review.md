## 概述

基于 CodeRabbit 的 AI 驱动代码审查。支持自主开发工作流，可以实现功能、审查代码并修复问题，无需手动干预。可检查代码质量、发现 Bug 和安全问题。

## 主要功能

- 审查暂存/未提交的代码变更
- 检查代码质量和安全问题
- 支持自主修复-审查循环
- 提供 PR 反馈和改进建议
