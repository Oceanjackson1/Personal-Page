## 概述

分析代码库模式，推荐针对性的 Claude Code 自动化方案。覆盖所有扩展选项，包括 hooks、子代理、技能、插件和 MCP 服务器。该技能是只读的，仅分析和输出建议，不创建或修改文件。

## 主要功能

- 分析代码库的工具、框架和库
- 推荐最有价值的 1-2 个自动化方案
- 覆盖 hooks、子代理、技能、插件等多种类型
- 支持针对特定类型的深入推荐
