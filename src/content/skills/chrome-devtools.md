## 概述

通过 MCP 使用 Chrome DevTools 进行网页调试、浏览器交互自动化、性能分析和网络请求检查。浏览器在首次工具调用时自动启动，使用持久化的 Chrome 配置。

## 主要功能

- 页面导航、快照和元素交互
- 网络请求监控和分析
- JavaScript 执行和控制台消息获取
- 截图和性能分析
- 表单填写和文件上传自动化
