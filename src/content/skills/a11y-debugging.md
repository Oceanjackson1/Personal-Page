## 概述

基于 web.dev 指南，使用 Chrome DevTools MCP 进行无障碍性调试和审计。覆盖语义 HTML、ARIA 标签、焦点状态、键盘导航、触摸目标和颜色对比度等方面的测试。

## 主要功能

- 通过 Lighthouse 审计获取全面的无障碍性基线评分
- 检查辅助功能树（Accessibility Tree）而非仅检查 DOM
- 测试键盘导航和焦点管理
- 验证颜色对比度和触摸目标尺寸
