## 功能概述

Code Review Skill 提供智能化的代码审查能力，帮助团队维护代码质量标准。

## 审查维度

- **代码质量** — 可读性、命名规范、代码复杂度
- **安全性** — 常见安全漏洞检测（XSS、SQL注入等）
- **性能** — 性能瓶颈识别和优化建议
- **最佳实践** — 框架和语言的最佳实践检查
